Build a Sorting Hat Simulator

Welcome to your next Computing challenge! Today, we will program our BBC micro:bits to act just like the famous magical Sorting Hat. When you shake the micro:bit, it will magically assign you to one of the four houses.

Gryffindor Slytherin Ravenclaw Hufflepuff

What You Need

  • 1x BBC micro:bit and battery pack
  • 1x USB Cable
  • MakeCode Editor (makecode.microbit.org)

Step-by-Step Instructions

Step 1: The Trigger

How does the Sorting Hat know when to sort? We need an input! Open a new project in MakeCode and find the Input menu.

Drag an on shake block into your workspace. Anything we put inside this block will run when the micro:bit is shaken.

Step 2: The Magic (Variables & Random Numbers)

The hat needs to make a choice. We will use a Variable to store this choice. Go to the Variables menu and create a new variable called house.

Drag the set house to block into your on shake block. Then, go to the Math menu and snap a pick random block into the value space. Set the numbers from 1 to 4.

on shake:
  set [house] to (pick random 1 to 4)

Step 3: The Logic (Selection)

Now we need Selection (If/Else statements) to decide what happens for each number. Go to the Logic menu and grab an if / else block.

Click the (+) button on the block until you have slots for all four houses. Build the logic like this:

if [house] = 1 then:
  show string "GRYFFINDOR!"
else if [house] = 2 then:
  show string "SLYTHERIN!"
else if [house] = 3 then:
  show string "RAVENCLAW!"
else:
  show string "HUFFLEPUFF!"

Step 4: Test and Download

Test your code in the on-screen simulator by clicking the "SHAKE" button. If it works, download the .hex file and flash it onto your micro:bit!

🧙‍♂️ Extension Challenge

Finished early? Try adding a custom icon for each house before the name scrolls across the screen! (e.g., a snake for Slytherin, a lion for Gryffindor). If you have a V2 micro:bit, can you make it play a magical sound effect when it sorts?
